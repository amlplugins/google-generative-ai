# @amlplugins/google-generative-ai

Native `@google/generative-ai` SDK re-exported under the `@amlplugins` namespace.

> Gemini API (Generative AI).

## Install

```bash
npm install @amlplugins/google-generative-ai
```

## Use

```ts
import { /* named exports from @google/generative-ai */ } from "@amlplugins/google-generative-ai";
// or
import sdk from "@amlplugins/google-generative-ai";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
